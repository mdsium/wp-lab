# WP-Lab

A WordPress project for learning and experimenting with WordPress themes, plugins, and custom development.

## Project Overview

This project is part of **WP-Lab**, focusing on:

- **WP Theme Development**: Creating custom WordPress themes from scratch.  
- **WP Plugin Development**: Building custom plugins to extend WordPress functionality.  
- **WordPress Core Concepts**: Hooks, filters, custom post types, widgets, and shortcodes.

---

## Features

### WP Theme
- Custom homepage and templates
- Dynamic menus and widgets
- Fully responsive design
- Theme options via `functions.php`
- **Reference**: [WordPress Theme Development Handbook](https://developer.wordpress.org/themes/)

### WP Plugin
- Custom plugin functionality
- Shortcodes for dynamic content
- Integration with theme templates
- Modular and reusable code
- **Reference**: [WordPress Plugin Handbook](https://developer.wordpress.org/plugins/)
